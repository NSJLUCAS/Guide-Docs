先按现象检查，不通过重装、清空数据库或关闭安全校验来试错。

## 面板打不开

官方安装默认只监听 `127.0.0.1:28080`。外部浏览器需要正确的 HTTPS 反向代理。先确认 Guide 服务与本机上游，再核对代理、DNS 和证书；代理 active 不等于最终访问链路成功。见[域名与 HTTPS](/install/reverse-proxy)。

## 网站卡片不出现

检查后台“服务”的公开和启用开关。公开导航只显示两者均开启的条目。检查当前分类和搜索条件；关闭在线检测不会单独隐藏卡片。

## 网站能打开却显示离线或受限

Guide 实例与浏览器处于不同网络。核对实例 DNS、证书和目标防护。普通错误码不等于检测受限；明确 Cloudflare 挑战才标受限，它不代表已确认网站可用。见[在线检测](/usage/checks)。

## 响应时间为什么是横线

受限、离线、未知和未检测没有可用于在线展示的延迟。旧结果超过 180 秒会过期；页面加载时间也不是这里的测量指标。不要把横线改成 0 毫秒作为“修复”。

## 图标库加载失败

新实例没有默认图库。核对图标库格式、无凭据 HTTPS 地址、浏览器网络和 CORS；图片可能另有鉴权或防盗链要求。未设置图片时使用通用图标，见[图标库与 favicon](/usage/icons)。

## 分类为空或不能删除

空分类可正常保留。后台计数包括私有和停用网站，而前台只显示公开且启用条目。有关联网站的分类需要先迁移全部网站，再删除，见[分类管理](/usage/categories)。

## GitHub 登录失败

核对自己的 OAuth App、HTTPS 回调和用户名白名单。空白名单拒绝所有 GitHub 用户。使用本实例应急密码登录“安全”页核对，不存在共享官方 OAuth secret。

## 忘记密码

按[登录与安全](/maintenance/security#忘记应急密码)，以有数据库权限的服务器用户运行 `--reset-password`。确认正在使用的真实现有 DB，不创建空库。重置会使旧 session 失效。

## 升级器未识别旧实例

立即停止。`not installed` 不证明机器没有旧数据。核对服务名、unit/drop-in、直接绝对 ExecStart、原数据库和支持范围，再按[旧实例接入](/maintenance/upgrade#旧实例首次接入)处理。

## 能否部署在 Docker 或 ARM

目前没有官方 Docker 镜像，官方安装/升级器不支持容器内运行或 ARM。正式附件为 Linux x86_64 GNU；自行构建兼容镜像不能等同官方支持。见[安装部署](/install/deployment#支持范围)。

## 可以直接回退旧二进制吗

数据库结构升级后，回退需要停止服务，恢复升级前完整 DB/WAL/SHM 快照和旧二进制。仅替换二进制不可靠。旧备份缺分类表被拒绝时，也不要删除数据绕过保护，见[备份](/maintenance/backup#恢复限制)。

## 去哪里反馈

普通问题在 [Guide Issues](https://github.com/NSJLUCAS/Guide/issues) 说明现象和版本，先移除账号、Cookie、数据库和 OAuth secret。安全问题按[安全报告规则](https://github.com/NSJLUCAS/Guide/blob/main/SECURITY.md)私下报告。本站每篇页面底部也提供 GitHub 编辑链接。
