未设置图标的网站显示通用地球图标。需要自己的图标时，可以添加图标库、填写 HTTPS 图片地址，或获取网站 favicon。新实例没有默认图标库。

## 配置图标库

在后台“设置”的图标库管理中添加名称和 HTTPS JSON 地址，选择当前图标库并保存。最多配置 20 个库。配置由实例保存，图库内容由管理员浏览器加载，不经过 Guide Hub 代理。

图库 URL 和图片 URL 必须是无登录凭据的 HTTPS 地址。地址应能被管理员浏览器访问，图库服务器需要允许合适的 CORS 访问；不要依赖登录 Cookie。

## 自建图标库格式

下面是格式示例。`example.com` 不是 Guide 提供的图库，把地址替换为有使用授权的真实资源。

```json
{
  "name": "我的图标库",
  "icons": [
    { "name": "文档", "url": "https://example.com/icons/docs.png" },
    { "name": "工具", "url": "https://example.com/icons/tools.svg" }
  ]
}
```

顶层需要非空 `name` 与 `icons` 数组。每项含名称和 HTTPS 图片地址；无效图片地址会被过滤，同地址去重。图库内容与图片授权由选用来源负责，不因用于 Guide 而自动变成 MIT。

## 给网站选择图标

在服务表单打开图标选择器，搜索并选择图库图片，或手动填写 HTTPS 图片地址。选择之后仍需保存服务；取消不会写入网站配置。

Guide 不内置网站品牌图标。需要特定品牌图像时，请选择有使用授权的图片来源。

## 获取网站 favicon

在服务表单手动获取网站图标。Guide 按安全策略查找候选，管理员确认后填入图标地址；不会自动替全部网站抓取，也不把图片集合打包到实例。

该候选获取有超时、重定向、内容大小和目标安全限制，不保证每个网站都能提取。确认图标后保存服务，前台由浏览器加载图片。

## 加载失败

先检查 JSON 格式、HTTPS、证书、网络及 CORS，再确认图片地址无防盗链或鉴权要求。图库请求失败可以重试；图片来源不可达时卡片仍有通用图标兜底。不要公开带有 token 或账号密码的图片链接。
