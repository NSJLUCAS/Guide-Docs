进入实例的 `/admin/` 登录。后台以网站与服务导航管理为中心；具体入口如下。

## 后台入口

| 菜单 | 路径 | 用途 |
| --- | --- | --- |
| 服务 | `/admin/services` | 网站新增、编辑、排序、公开/私有与检测开关 |
| 分类 | `/admin/categories` | 独立分类、空分类、顺序和关联数量 |
| 主题 | `/admin/themes` | 主题与导航外观、卡片样式 |
| 安全 | `/admin/security` | 应急密码、GitHub OAuth 和登录白名单 |
| 设置 | `/admin/settings` | 站点设置及图标库配置 |

表内地址属于你自己的实例，不是本站的文档路径。当前后台没有“数据”菜单；备份通过受认证接口完成，见[数据备份](/maintenance/backup)。

## 建议操作顺序

先在“安全”修改首次生成的应急密码，然后创建[分类](/usage/categories)并添加[网站](/usage/websites)。配置需要的[图标库](/usage/icons)，最后选择[卡片布局](/usage/layout)。

操作成功后确认保存提示，再打开公开导航检查。保存失败时保留表单并根据提示重试，不把未保存的预览当作实例设置。

## 前台与后台的区别

管理员可以管理私有和停用网站；公开导航仅返回同时公开且启用的网站。后台分类数量包含全部关联网站，前台统计只涉及公开且启用的网站，因此两处数量可能不同。

浏览器偏好（如深浅色）和实例设置（如卡片布局）不同。前者随当前浏览器保存，后者由后台保存并用于全站导航。

## 登录异常

GitHub OAuth 是可选功能，未配置时可使用本实例应急密码。白名单为空不会允许所有 GitHub 用户。无法登录时阅读[登录与安全](/maintenance/security)，不要重新安装覆盖原数据库。
