后台进入“设置”，在导航外观中选择卡片样式。它是由实例保存的全站设置，不是只对当前管理员浏览器生效。

## 三种卡片

| 后台标签 | 用途 |
| --- | --- |
| 标准卡片 | 保留较完整的卡片空间，适合一般导航 |
| 小卡片 | 更紧凑地排列较多网站 |
| 极简卡片 | 以精简入口呈现导航 |

这些样式只调整展示密度，不修改网站地址、权限或检测规则。各样式都按真实状态处理检测受限与未知，不生成虚假响应时间。

## 保存与同步

选中样式后点击“保存卡片样式”。保存成功后，公开导航会同步更新。必要时刷新公开页面确认。

加载失败时先重试加载，避免在不知道原设置时覆盖配置；保存失败不当作成功。较旧实例缺少设置能力时应先检查版本兼容。

## 分类抽屉

在公开导航点击某个分类时，该分类的卡片会以抽屉动画展开。“全部”和搜索保持原样；系统开启“减少动态效果”时直接切换，不播放动画。

## 页脚动画

公开导航底部有一个打着手电找东西的小人，在页面底部来回走动。在“设置 → 导航外观”的“页脚动画”开关中可以关闭，切换后立即生效，无需点击保存。关闭后底部仍保留指向 Guide 项目的 GitHub 入口。系统开启“减少动态效果”时小人静止不动。

## 深浅色

公开导航可切换浅色和深色。颜色偏好保存在当前浏览器中，不会替所有访客切换。

## 主题与手机

默认 Guide 导航已内嵌在正式二进制。自定义主题属于可选配置；使用自己的主题时由其实现决定支持哪些导航设置。

三种布局都支持响应式访问。选择密度时在桌面和手机检查名称、图标和状态可读性，较多网站可结合分类和搜索，而不需要增加卡片字段。
