在线检测由你部署的 Guide 实例执行，用于提供最近一次有限 HTTP 请求的状态参考。文档站不会代替实例发起检测。

## 检测规则

当前正式实现固定每 60 秒检查，单次整体超时 5 秒，最多并发 4 个目标。只处理响应头，不读取响应正文，不跟随重定向。

响应时间衡量请求开始到收到响应头的时间，不是网页完整加载时间，也不是访客网络延迟。结果保存最近一次数据，超过 180 秒按过期处理。

## 状态说明

| 状态 | 含义 |
| --- | --- |
| 在线 | 收到 2xx 或 3xx 响应；3xx 不继续跟随目标 |
| 离线 | 请求失败、超时，或收到其他不满足受限条件的错误响应 |
| 检测受限 | 明确遇到 Cloudflare 验证挑战；没有已确认可用结论，也不显示虚假响应时间 |
| 未知 | 尚无有效结果，或结果已经过期等情况 |
| 未检测 | 在线检测开关关闭；网站卡片仍可展示 |

2xx/3xx 优先判在线。仅明确的 `cf-mitigated: challenge` 挑战标记才标检测受限；普通 403、429、503 或 Cloudflare 基础响应头本身不足以判断。受限状态在 v1.2.0 正式发布。

## 过期与响应时间

无法持续取得新结果时，旧状态会过期，不把先前的在线状态永久保留。离线、未知、未检测及受限不显示伪造延迟。一个显示受限的链接仍可由访客打开，但这不表示 Guide 已确认它在线。

## 安全与网络

目标 URL 和实际 DNS 地址都会检查，拒绝回环、链路本地、元数据和其他明确危险地址；不使用环境代理，不通过跳转绕过目标限制。普通私网按当前策略允许。

浏览器与实例网络位置可能不同：本地可访问的网站，实例可能因 DNS、证书、防护或网络策略失败。不要通过关闭安全限制或提供登录凭据来强行检测。

## 开关与排查

在后台“服务”中控制在线检测。停用条目不参与周期检测；关闭检测不影响符合展示条件的卡片。

出现异常时先核对网址、检测开关、启用状态与实例网络，再确认是否为验证挑战或过期数据。FAQ 见[常见问题](/reference/faq#网站能打开却显示离线或受限)。
