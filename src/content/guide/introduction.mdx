Guide 是一个自托管的网站与服务导航门户。把常用网站集中成卡片，用分类和搜索找到入口，同时查看最近的在线状态和响应时间。

## 可以做什么

- **管理网站：**添加、编辑、删除和排序，分别控制公开可见、启用及在线检测。
- **组织分类：**独立新增、更名和排序，保留空分类；前台以“全部”开始。
- **选择图标：**配置多个 HTTPS 图标库，手动获取网站 favicon，或填写自己的图片地址。
- **了解状态：**区分在线、离线、检测受限、未知与未检测；过期结果不会冒充最新状态。
- **调整布局：**标准卡片、小卡片、极简卡片，配合深浅色和响应式页面。
- **保护后台：**实例独立应急密码与可选 GitHub OAuth 登录。

## 组成与数据

Guide 实例使用 Rust 和 SQLite，管理后台与导航使用 React/TypeScript。默认前端静态资源已内嵌到 `guide-hub`，运行正式二进制无需另启动 Node.js 前端服务。数据库和配置由实例管理员保管。

这份文档站是独立静态网站。阅读文档不需要运行 Guide；实际在线检测和管理数据发生在你自己的 Guide 实例中。文档站可以只托管在 Cloudflare Pages，Guide 实例的部署请阅读[安装部署](/install/deployment)。

## 适合谁

适合整理个人常用网站、家庭服务或团队入口。公开卡片用于导航，私有或停用的网站不会出现在公开页面。分类属于全局公开导航元数据，不要在分类名称中放入秘密。

在线状态是实例所在网络的一次有限 HTTP 检测结果，不是浏览器完整访问体验，也不是服务可用性的保证。有关含义见[在线检测](/usage/checks)。

## 正式功能范围

本站内容核对于正式 v1.2.0。分类管理和检测受限已正式发布，不是待发布功能。正式版本与更新说明以 [GitHub Releases](https://github.com/NSJLUCAS/Guide/releases) 为准。

Guide 不提供官方 Docker 镜像；官方安装器支持范围见安装页。本站不把上游服务器探针的 Agent、节点流量或通知教程当作 Guide 导航功能。项目来源与保留的兼容边界见[许可与来源](/reference/licenses)。
