Guide 是一个自托管的网站与服务导航门户。把常用网站集中成卡片，用分类和搜索找到入口，同时查看最近的在线状态和响应时间。

## 可以做什么

- **管理网站**：添加、编辑、删除和排序，分别控制公开可见、启用及在线检测。
- **组织分类**：新增、更名和排序，保留空分类；前台以“全部”开始。
- **选择图标**：配置 HTTPS 图标库、获取网站 favicon，或填写自己的图片地址。
- **了解状态**：区分在线、离线、检测受限、未知与未检测；过期结果不会冒充最新状态。
- **调整布局**：标准卡片、小卡片、极简卡片，配合深浅色和响应式页面。
- **保护后台**：实例独立应急密码与可选 GitHub 登录。

## 如何使用

Guide 需要部署在自己的服务器上。正式安装包包含导航页面和管理后台，无需另外启动前端服务。网站、分类、设置和认证信息保存在服务器的 SQLite 数据库中，由管理员保管。

第一次使用时，从[快速开始](/guide/quick-start)了解操作顺序；准备部署服务器时阅读[安装部署](/install/deployment)。已有实例的用户可直接阅读[后台使用](/usage/admin)。

## 适合谁

适合整理个人常用网站、家庭服务或团队入口。公开卡片用于导航，私有或停用的网站不会出现在公开页面。分类属于全局公开导航元数据，不要在分类名称中放入秘密。

在线状态是实例所在网络的一次有限 HTTP 检测结果，不是浏览器完整访问体验，也不是服务可用性的保证。有关含义见[在线检测](/usage/checks)。

## 正式功能范围

本文档适用于正式 v1.2.0。其他版本的功能和升级说明见[版本与下载](/guide/releases)。

官方安装器支持 Linux x86_64、glibc 和 systemd，目前没有官方 Docker 镜像。完整平台要求见[安装部署](/install/deployment#支持范围)，版权和第三方授权见[许可与来源](/reference/licenses)。
