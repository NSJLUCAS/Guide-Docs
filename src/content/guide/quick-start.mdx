已有 Guide 实例时，直接登录后台开始使用；首次部署时，先完成服务器安装。服务器上已有 Guide 数据时，请按[旧实例首次接入](/maintenance/upgrade#旧实例首次接入)处理，不要执行新安装来覆盖原数据。

## 已有实例

打开自己的 Guide 域名，进入 `/admin/`。使用该实例的应急密码，或管理员已配置的 GitHub 登录方式。

忘记密码时按[账号恢复](/maintenance/security#忘记应急密码)处理。Guide 没有官方统一密码，也不通过邮箱恢复。

## 首次部署

确认服务器满足[支持范围](/install/deployment#支持范围)，且不存在旧实例。按[安装部署](/install/deployment#首次安装)下载并校验安装器，成功后配置自己的 HTTPS 反向代理。

默认 Guide 仅监听 `127.0.0.1:28080`，不能直接从外部浏览器连接该服务器的 loopback 地址。需要域名时阅读[域名与 HTTPS](/install/reverse-proxy)。第一次登录后，在“安全”页面立即设置自己的应急密码。

## 添加第一个网站

1. 后台进入“分类”，创建一个分类，例如“常用”。
2. 进入“服务”，点击新增服务，填写名称和无登录凭据的 HTTP/HTTPS 地址。
3. 选择分类；图标可以暂时留空，使用通用图标。
4. 根据需要开启“公开”“启用”和“在线检测”，保存。
5. 返回公开导航，确认卡片可见并可打开。需要检测时等待下一轮结果。

公开导航仅展示同时公开且启用的网站。关闭在线检测仍可展示卡片，但不会显示在线状态。字段说明见[网站管理](/usage/websites)。

## 调整日常体验

在后台“主题”中选择[卡片布局](/usage/layout)，在[图标库](/usage/icons)配置可访问的图库。公开导航支持分类筛选与搜索，深浅色切换是浏览器偏好。

开始正式使用前保存[一致性备份](/maintenance/backup)。维护时用 `sudo guide-update --check` 只读检查更新，升级步骤见[升级与回退](/maintenance/upgrade)。
