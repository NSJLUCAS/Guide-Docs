正式版本、Release Notes 和下载附件统一由 [GitHub Releases](https://github.com/NSJLUCAS/Guide/releases) 提供。默认安装入口使用[最新稳定版本](https://github.com/NSJLUCAS/Guide/releases/latest)，升级前阅读目标版本的兼容说明。

## 选择版本

本文档适用于 v1.2.0。首次安装通常选择最新稳定版本；官方安装器运行时也会选择最新稳定版本。已有实例先阅读[升级与回退](/maintenance/upgrade)，不要直接执行首次安装。

| 正式版本 | 主要区别 |
| --- | --- |
| [v1.0.0](https://github.com/NSJLUCAS/Guide/releases/tag/v1.0.0) | 下载附件只有程序归档及独立 SHA 校验文件；已有实例接入升级器须先核对部署 |
| [v1.1.0](https://github.com/NSJLUCAS/Guide/releases/tag/v1.1.0) | 提供官方安装与升级器、下载校验、备份与失败恢复 |
| [v1.2.0](https://github.com/NSJLUCAS/Guide/releases/tag/v1.2.0) | 新增分类管理、空分类与排序，以及 Cloudflare 检测受限状态 |

完整变化、下载附件与兼容限制见对应版本的发布页。安装正式发布的版本，避免把尚未发布的代码当作稳定版本使用。

## 下载与校验

从官方 Release 下载程序归档、独立 `.sha256` 和 `sha256sums.txt`，并按[安装步骤](/install/deployment)校验。获取指定版本时使用同一版本的整组附件，不混用不同版本或旧清单。校验失败立即停止。

下载历史版本安装器不会固定它运行时安装的 Guide 版本。需要指定历史版本时，按[手动部署](/install/deployment#手动部署)处理。
