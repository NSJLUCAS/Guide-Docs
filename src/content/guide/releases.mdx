正式版本、Release Notes 和下载附件统一由 [GitHub Releases](https://github.com/NSJLUCAS/Guide/releases) 提供。默认安装入口使用[最新稳定版本](https://github.com/NSJLUCAS/Guide/releases/latest)，升级前阅读目标版本的兼容说明。

## 本站内容基线

本站在 2026-10-08 核对正式 v1.2.0。它是文档功能依据，不是锁定安装器下载版本；安装器运行时仍选择 latest 稳定 Guide。

| 正式版本 | 适用范围 |
| --- | --- |
| [v1.0.0](https://github.com/NSJLUCAS/Guide/releases/tag/v1.0.0) | 历史正式版本；附件仅归档和独立 SHA，没有官方安装器或汇总校验清单 |
| [v1.1.0](https://github.com/NSJLUCAS/Guide/releases/tag/v1.1.0) | 官方安装/升级器、下载校验、备份与失败恢复；schema 13 |
| [v1.2.0](https://github.com/NSJLUCAS/Guide/releases/tag/v1.2.0) | 独立分类、空分类与排序、前台同步、Cloudflare 检测受限；schema 14 |

这里仅说明文档适用范围，不另维护一份完整 Release Notes。更详尽的变化和限制请查看对应正式发布页。GitHub main 上出现的代码不一定已经发布；未进入正式 Release 的功能必须按开发中看待。

## 演示站

Guide 独立演示站正在开发，地址尚未在本站确认。部署文档站时可配置已确认的演示站入口；配置之前，“查看演示”会回到本节，不假设演示站已经上线。

演示站与官方文档站都是配套站点开发，不宣称已随 v1.2.0 二进制发布。真实实例安装仍使用 Guide 自己的正式 Release 附件。
